================================================================================
BLOQUE B: COMPOSE CON REDES Y VOLÚMENES
================================================================================

1. docker compose -f docker-compose-completo.yml up -d
[+] Running 5/5
 ✔ Network compose-practica_red-interna  Created
 ✔ Volume compose-practica_datos-app     Created
 ✔ Volume compose-practica_datos-db      Created
 ✔ Container db-servicio                 Started
 ✔ Container app-servicio                Started

2. Verificación de Red y Volúmenes
docker network ls | grep red-interna -> compose-practica_red-interna (OK)
docker volume ls | grep datos -> compose-practica_datos-app, compose-practica_datos-db (OK)

3. docker compose down
[+] Running 3/3
 ✔ Container app-servicio  Removed
 ✔ Container db-servicio   Removed
 ✔ Network red-interna     Removed

4. Verificación de Persistencia (Post-down)
docker volume ls | grep datos
(Los volúmenes PERSISTEN después del comando down, garantizando la seguridad de los datos).
